Hotel Room Booking System

A simple console-based Hotel Room Booking System developed using Python.

Features

- Display available room types and prices
- Select Single, Double, or Deluxe Room
- Calculate total room cost based on number of days
- Add a fixed service charge
- Apply discounts based on stay duration
- Generate a detailed booking bill
- Validate room selection and number of days

Room Pricing

- Single Room – Rs. 1500/day
- Double Room – Rs. 2500/day
- Deluxe Room – Rs. 4000/day

Technologies Used

- Python
- Functions
- Conditional Statements
- User Input/Output
- Arithmetic Operations

How to Run

1. Install Python.
2. Save the program as "hotel_booking.py".
3. Open the terminal in the project folder.
4. Run:

python hotel_booking.py

Learning Outcome

This project demonstrates the use of Python functions, conditional logic, calculations, input validation, and modular programming to build a simple real-world application.
